LUMIO · TEMİZ MASA, TEMİZ EKRAN
CLEAN DESK, CLEAN SCREEN

TÜRKÇE

Masadan kalkarken
[ ] Ekranı kilitle (Windows: Win + L, macOS: Ctrl + Cmd + Q).
[ ] Kişisel veri içeren belgeleri kilitli dolaba kaldır.
[ ] Yazıcıda belge bırakma; çıktıyı hemen al.

Gün sonunda
[ ] Masada belge, not ya da şifre yazılı kâğıt bırakma.
[ ] Artık gerekmeyen belgeleri kırpıcıdan geçir.
[ ] Taşınabilir bellekleri ve dizüstü bilgisayarı kilitle.

Ekranda
[ ] Ekranı ziyaretçilerin göremeyeceği şekilde konumlandır.
[ ] Paylaşılan ekranda yalnızca gereken pencereyi göster.

ENGLISH

When you leave your desk
[ ] Lock the screen (Windows: Win + L, macOS: Ctrl + Cmd + Q).
[ ] Put documents with personal data in a locked cabinet.
[ ] Do not leave prints in the printer; collect them at once.

At the end of the day
[ ] Leave no documents, notes or written passwords on the desk.
[ ] Shred documents that are no longer needed.
[ ] Lock away removable drives and the laptop.

On screen
[ ] Place the screen where visitors cannot read it.
[ ] When sharing a screen, show only the window that is needed.
